Anpasser's source-flow analysis (`tools/subsystem_flow.py`) summarises a read-only leaf function with `leaf_effects`, which returns nothing for any function that writes memory or calls something. Functions that do write, such as the original program's window procedures, still have a calling convention the converter can *enforce* instead of trust: if every return of the function is the same textbook source `RET` cleanup, a native caller can check, right after the call, that the stack pointer and the return address are what the original program would have left. Add that as a new function, `normal_return_contract(function)`, in `tools/subsystem_flow.py`.

`function` is the same dict the other analyses take: `{"address": ..., "instructions": [{"address", "fallthrough"?, "operations": [...]}, ...]}`, with Ghidra P-Code operations (`opcode`, `inputs`, optional `output`, optional `memory_space`) whose varnodes are `{"space", "offset", "bytes"}` with the offset as a string. Register 16 is `ESP`, register 644 the instruction pointer.

It returns `None` unless all of these hold, and otherwise a checked postcondition:

- No operation anywhere in the function is a `BRANCHIND`, and no `BRANCH` or `CBRANCH` whose target is a `ram` address leaves the function (a target that is not the address of one of the function's own instructions).
- Every `RETURN` is the last operation of its instruction and has at least two operations before it in that same instruction. The first of those is a `LOAD` with `memory_space` `ram` whose output is the 4-byte instruction pointer register (644) and whose address input (the second input) is the 4-byte `ESP` register; the `RETURN`'s single input is that same loaded varnode. Every remaining operation before the `RETURN` is an `INT_ADD` whose output is the 4-byte `ESP`, whose first input is `ESP` again and whose second input is a 4-byte constant. The sum of those constants is the cleanup `delta`, and it must be a multiple of 4 between 4 and 260 inclusive.
- All returns of the function agree on the same `delta`, and there is at least one return.

The result is `{"argument_bytes": delta - 4, "source_stack_delta": delta, "memory_effect": "unknown", "preserved_registers": [], "analysis_only": True, "requires_native_call_guard": True, "proof": "uniform-source-RET-cleanup-with-enforced-caller-postcondition"}`. It deliberately proves nothing about the body (the body may write memory and clobber every register); it only supplies the postcondition that the compiler must enforce at each modeled caller, which is why `memory_effect` is `unknown` and no register is preserved.

Then use it in `tools/whole_program.py`: when `prepare` builds the whole-program report, compute the contract for every recovered function, keep the ones that are not `None` as `source_return_contracts` (a map from function address to contract) inside the native-subsystems record, and report `checked_source_returns` as `{"callees": <how many>, "stack_delta_and_return_pc_enforced": True}`. The emitter then wraps every direct `CALL` to such a function (one that has a `fallthrough` address, to the address in `ram` space) in a block that reads the return address on top of the source stack before the call and aborts with `fatal(s, "source call return frame", <target>)` if it is not the fallthrough address, performs the call, and afterwards aborts with `fatal(s, "source call return postcondition", <target>)` unless `REG(16)` equals the old stack pointer plus `delta` and `REG(644)` equals the fallthrough address. The graded tests exercise this wiring only on Linux x86-64, so it will not run for you on other machines, but implement it.

Graded by new tests in `tools/test_subsystem_flow.py` (not in your copy of the repository; the file imports `normal_return_contract` at the top, so until the function exists the whole file fails to import): a writing body (a leaf with a store added) has no pure `leaf_effects` summary but has a `normal_return_contract` with `requires_native_call_guard` true, no preserved registers and `memory_effect` `unknown`; moving the `RET`'s stack read to `EAX` instead of `ESP` gives `None`; appending a `BRANCHIND` gives `None`. The other tests of that file and of `tools/test_whole_program.py` must keep passing.
