Create a temperature conversion command, `convert.js`, run as `node convert.js <value><unit> <target-unit>`. Units are `C`, `F` and `K` (case-insensitive). It prints the result rounded to one decimal place followed by the target unit, for example `node convert.js 100C F` prints `212.0F` and `node convert.js -40f c` prints `-40.0C`. Invalid input (a bad number, an unknown unit, the wrong number of arguments) or a temperature below absolute zero prints an error message to stderr and exits with code 2. Put the conversion logic in a function that can be imported and tested separately, and add tests.
