Let environment variables override settings in `loadConfig`. For every key in the defaults, an environment variable named `APP_` followed by the key in upper snake case overrides it (`maxRetries` is set by `APP_MAX_RETRIES`, `logLevel` by `APP_LOG_LEVEL`). The value is converted to the type of the default: numbers must parse as finite numbers, booleans accept `true`/`false`/`1`/`0` (case-insensitive), strings are used as they are. An invalid value throws an `Error` whose message names the variable. Precedence, highest first: environment, the file, the defaults. `loadConfig` takes the environment as an optional second argument (default `process.env`) so it can be tested.
