Implement `retry` in `src/retry.ts`. It calls the async function `fn` until it succeeds or `attempts` calls have failed, then rejects with the last error. Between attempts it waits `delayMs` milliseconds, multiplied by `factor` after each failure (so with `delayMs: 100, factor: 2` the waits are 100, 200, 400 ms). Defaults: `attempts: 3`, `delayMs: 0`, `factor: 1`. If `shouldRetry(error)` is given and returns false, it rejects at once without retrying. `onRetry(error, attempt)` is called before each wait, with the number of the attempt that just failed (starting at 1). Keep the existing exported types.
