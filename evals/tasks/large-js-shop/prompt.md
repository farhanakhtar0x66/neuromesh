Build a small shop library and command line tool in this project. It has five parts. Amounts are always integers in cents.

1. `src/money.js` exports `formatCents(cents)`: dollars with a thousands separator and two decimals. `123456` gives `"$1,234.56"`, `5` gives `"$0.05"`, `-500` gives `"-$5.00"`.

2. `src/inventory.js` exports `OutOfStockError` (a subclass of `Error` with the properties `item`, `requested` and `available`, and the message `Out of stock: <item> (requested <n>, available <m>)`) and `class Inventory`. `new Inventory(stock)` takes an object mapping product names to quantities. Methods: `stock(name)` (0 for unknown products), `add(name, qty)` and `remove(name, qty)`, where qty must be a positive integer or a `RangeError` is thrown, and `remove` throws `OutOfStockError` when there is not enough; and `lowStock(threshold)`, the names whose stock is below the threshold, sorted alphabetically.

3. `src/cart.js` exports `class Cart`. `new Cart(prices, { taxRate = 0.08 } = {})` takes an object mapping product names to unit prices. `add(name, qty = 1)` adds to the cart; adding a product already in the cart increases its quantity; an unknown product throws `Error("Unknown product: <name>")`. `lines()` returns `{ name, qty, unitCents, totalCents }` in the order products were first added. `subtotalCents()`. `applyCode(code)`: `SAVE10` takes 10% off the subtotal (rounded to the nearest cent), `FLAT500` takes 500 cents off; the discount never makes the amount negative; only one code applies at a time (a new code replaces the old one); an unknown code throws `Error("Unknown code: <code>")`. `discountCents()`, `taxCents()` (the tax rate times the discounted amount, rounded to the nearest cent) and `totalCents()` (subtotal minus discount plus tax).

4. `src/orders.js` exports `placeOrder(cart, inventory)`. It checks every line of the cart first; if any product lacks stock it throws the `OutOfStockError` for the first such line in cart order and changes nothing. Otherwise it removes the stock and returns `{ id, lines, subtotalCents, discountCents, taxCents, totalCents }`, where `id` counts up from 1 for each order placed in the process.

5. `bin/shop.js`, run as `node bin/shop.js <store.json> <order.json>`. The store file is `{ "prices": {...}, "stock": {...}, "taxRate": 0.08 }` (taxRate optional) and the order file is `{ "items": [{ "name": "...", "qty": 2 }], "code": "SAVE10" }` (code optional). It places the order and prints one line per cart line, `<qty> x <name> @ <unit price> = <line total>`, then `Subtotal: <amount>`, `Discount: -<amount>` (only when there is a discount), `Tax: <amount>` and `Total: <amount>`, with every amount formatted by `formatCents`. If an item is out of stock it prints the error message to stderr and exits with code 1. Wrong arguments, an unreadable file or invalid JSON print a message to stderr and exit with code 2.

Add tests for every part.
